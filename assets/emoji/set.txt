# surfer's emoji set — the source of truth for BOTH the baked atlas and
# the names you can reach it by (`surfer.emoji("fire")`).
#
# One line per emoji: NAME CODEPOINT. Names are lower_snake, chosen to be
# typed rather than to match Unicode's official names, which are long and
# shouty ("GRINNING FACE WITH SMILING EYES"). The codepoint is what the
# font is keyed on, so `"\U0001F525"` and `surfer.emoji("fire")` are the
# same glyph by construction.
#
# WHY A CURATED SET AND NOT ALL OF UNICODE. An emoji is a 16x16 ARGB
# picture — 1 KB each, against a whole-build atlas budget of 1.25 MiB. The
# ~4,000 Unicode has would be 4 MiB at one size. The top 100 emoji are
# ~82% of all use (Unicode's own frequency data), so a couple of hundred
# is most of the value for 5% of the bytes. Add a line and rebuild to
# extend it.
#
# Art: Twemoji (github.com/jdecked/twemoji), graphics CC-BY 4.0 — see
# LICENSE.txt in this directory. Sequences (flags, skin tones, ZWJ
# families) are deliberately absent: they are several codepoints that
# have to be composed, and surfer's text path is one codepoint per glyph.
